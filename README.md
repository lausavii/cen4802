# CEN 4802 - Task Tracker

**By:** Laura Savinon

## Description:

I created a Test Tracker called my to-do list.
This application allows users to view and add tasks through a web browser.

The application is built using Java, Spring Boot, Maven, and Thymeleaf. 
Bootstrap is used for basic styling.

## Purpose:

This application was created as the base for showing version control 
and DevOps practices throughout the course.
